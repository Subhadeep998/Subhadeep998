# Security policy

## Reporting a problem

If you find a security issue in this repository — for example a malicious link, a compromised dependency,
or a way to tamper with the automated updates — please **do not open a public issue**.

Report it privately instead:

- **Preferred:** use GitHub's [private vulnerability reporting](https://github.com/Subhadeep998/subhadeep998/security/advisories/new)
- **Or email:** info@subhadeepaditya.in

You'll get a reply within 7 days.

## How this repository is protected

- Only the owner can change the content; outside changes arrive as pull requests and need the owner's review.
- Automated workflows run with the minimum permissions they need and use actions pinned to exact, verified versions.
- Third-party actions are checked monthly for updates by Dependabot.
- Content links point to official sources; report anything that looks wrong.
